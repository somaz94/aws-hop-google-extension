AWS Hop은 AWS 콘솔 계정을 클릭 한 번으로 전환하고, 콘솔 탭마다 지금 어느 계정인지 표시해 운영 계정을 테스트 계정으로 착각하지 않게 해 줍니다.

비밀번호, 액세스 키, 세션 토큰을 묻지 않습니다. 로그인은 늘 AWS 페이지에서 이루어지고, AWS Hop은 어디로 보낼지만 압니다.

로그인 방식
- IAM 사용자 로그인: 계정이 채워진 로그인 페이지를 엽니다
- Switch Role: 계정, 역할, 표시 이름, 색이 채워진 역할 전환 페이지를 엽니다
- IAM Identity Center(SSO): 액세스 포털을 거쳐 콘솔을 엽니다. awsapps.com과 app.aws 포털을 모두 지원합니다
- 사용자 지정 URL: Okta, Entra ID, Google Workspace의 IdP 시작 SAML 링크 같은 모든 로그인 링크

계정 표시
- 모든 AWS 콘솔 페이지에 색 줄과 라벨을 띄워 이 탭이 어느 계정, 어느 역할인지 보여 줍니다
- 보호 계정은 빨간 테두리를 두르고 탭 제목 앞에 계정 이름을 붙입니다
- 툴바 아이콘에 탭의 태그를 배지로 보여 주고, 보호 계정은 빨간 배지로 표시합니다
- 라벨은 왼쪽 아래와 오른쪽 아래 중 원하는 곳에 둘 수 있습니다
- 목록에 없는 계정은 회색 라벨로 표시하고, 팝업에서 바로 추가할 수 있습니다
- 라벨을 누르면 콘솔 페이지에서 바로 다른 계정으로 전환합니다

내 계정, 내 라벨
- 자유로운 태그(prod, qa, 프로젝트 이름), 프로젝트별 색, 보호 계정 표시
- 옵션 페이지에서 목록을 그룹별로 보고, 검색하고, 끌어서 순서나 그룹을 바꾸고, 여러 계정의 태그, 그룹, 보호 여부를 한 번에 바꿀 수 있습니다
- 팝업에서 입력해 거르고 화살표 키와 Enter로 엽니다. Alt+Shift+A로 팝업을 엽니다. 최근에 연 계정이 먼저 나오고, 보호 계정은 Enter를 두 번 눌러야 열리게 할 수 있습니다
- 팝업 없이 주소창에 aws와 계정 이름을 입력해도 됩니다
- 콘솔의 다중 세션을 켜 두면, 이미 로그인된 계정은 세션 선택 화면 없이 그 세션으로 바로 열립니다
- ~/.aws/config(프로필이 여러 개여도 계정당 하나), aws-extend-switch-roles 설정, JSON 내보내기에서 가져옵니다. 미리보기에서 원하지 않는 계정은 빼고 가져올 수 있습니다
- 모든 AWS CLI 프로필의 계정 ID를 찾는 명령을 macOS, Windows(PowerShell), Linux용으로 바로 복사할 수 있습니다
- 계정 목록은 Chrome 브라우저 사이에 동기화됩니다
- 영어와 한국어 지원, 라이트와 다크 테마 또는 시스템 설정 따르기

개인정보
- 입력한 계정 이름, 계정 ID, 역할 이름, 포털 URL, 라벨만 Chrome 동기화 저장소에 저장합니다. 최근에 연 목록과 열린 콘솔 세션 주소는 이 브라우저에만 남습니다
- 네트워크 요청, 분석, 서버가 없습니다
- 오픈 소스: https://github.com/somaz94/aws-hop-google-extension

AWS Hop은 Amazon Web Services와 제휴하거나 보증을 받은 제품이 아닙니다.
