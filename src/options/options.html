Accounts are stored in Chrome sync storage. No passwords or access keys are ever stored.

    Import

    Paste an AWS Hop export (JSON) or an AWS CLI config file. sso_* profiles become IAM Identity Center links, role_arn profiles become Switch Role, and aws_account_id profiles become IAM user sign-in. Optional env and color keys are read too.

    Export

    Download every account as JSON, to back up or move to a browser that does not sync.
